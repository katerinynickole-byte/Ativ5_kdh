# Guerreiras do Kpop — KPop Demon Hunters

## Sobre o projeto

Este projeto foi desenvolvido como atividade de HTML Avançado.

O site é inspirado no filme **KPop Demon Hunters** e apresenta informações sobre as personagens, os grupos HUNTR/X e Saja Boys, além de conteúdos relacionados à história do filme.

## Objetivo

O objetivo do projeto é colocar em prática os conhecimentos de HTML, utilizando:

- Tags semânticas;
- Links entre diferentes páginas;
- Tabelas;
- Formulários;
- Imagens;
- Áudio;
- Vídeo;
- Elementos interativos;
- Tags de texto avançado.

## Estrutura do projeto

O projeto está organizado da seguinte forma:

- `html/` — contém as páginas HTML do site;
- `img/` — contém as imagens utilizadas no projeto;
- `audio/` — contém os arquivos de áudio;
- `video/` — contém os arquivos de vídeo.

## Páginas

O site possui mais de 10 páginas HTML, incluindo:

- Página inicial;

- Jinu;
- Abby;
- Romance;

## Tecnologias utilizadas

- HTML5
- Git
- GitHub

## Observação

O projeto foi desenvolvido utilizando exclusivamente HTML, sem utilização de CSS ou JavaScript, conforme as regras da atividade.
